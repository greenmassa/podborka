# podborka

Сервис собирает трендовые товары, которые набирают популярность, и оценивает их цитируемость в социальных сетях.

## Как работает

1. **Запрос** — отслеживаемый товар или тема: ключевые слова, хэштеги, @упоминания и список соцсетей (YouTube, Instagram, X, Telegram, TikTok).
2. **Сборщики** по каждой сети находят посты и видео и снимают их счётчики: просмотры, лайки, комментарии, репосты, подписчики автора.
3. Каждый сбор пишет **снимок** счётчиков в SQLite, поэтому видно, как растут реакции.
4. **Метрики** (`src/podborka/metrics.py`):
   - вовлечённость: (лайки + комментарии + репосты) / просмотры, а без просмотров — / подписчики автора;
   - скорость: прирост реакций в час между двумя последними снимками; для первого снимка — реакции / часы с публикации (не меньше 0,5 ч);
   - тренд товара: упоминания за последние 24 ч против предыдущих 24 ч.

## Запуск

```bash
uv sync
uv run python -m podborka seed            # демо-данные в podborka.db
uv run python -m podborka serve --demo    # http://127.0.0.1:8000
```

Страницы:
- **Сводка** — товары с ростом упоминаний и самые быстрые посты; фильтр по категории и «только растущие» (рост упоминаний от ×1,5).
- **Лента** — поиск по тексту; фильтры по товару, категории, соцсетям (несколько сразу), дате публикации; в «Ещё фильтрах» — формат (пост/видео), размер автора (микро/средние/крупные/мега), минимум реакций, просмотров и скорости, «найдены впервые». Сортировка по скорости, вовлечённости, реакциям, новизне. Фильтры сохраняются в адресе страницы.
- **Карточка поста** — график роста реакций и история сборов.
- **Товары** — добавить/изменить товар (с категорией) и «Собрать сейчас».

`--demo` подключает демо-сборщики, которые генерируют правдоподобные посты. Без флага сбор пока ничего не находит — реальные API подключаются на следующих шагах.
